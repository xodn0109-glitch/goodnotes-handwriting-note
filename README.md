# 굿노트 요약노트 만들기

교과서 원문을 바탕으로 **학생용·교사용 요약노트 PDF**를 만드는 Codex 스킬입니다. 자료의 단원·소단원 체계를 유지하고, 2022 개정 교육과정 성취기준을 참고해 핵심 개념과 학습 관계를 정리합니다. 여러 출판사 교재를 제공하면 **내가 사용하는 교과서를 중심으로 부족한 내용을 보완**할 수 있습니다.

## 이렇게 사용하세요

1. Codex에서 노트를 만들 작업 폴더를 엽니다. 폴더 이름은 자유롭게 정할 수 있습니다.
2. 교과서 PDF나 캡처 자료를 폴더에 넣거나 채팅에 첨부합니다.
3. **“노트 만들어줘”**라고 요청합니다. 필요한 경우 과목, 단원, 페이지 범위를 함께 적습니다.

```text
이 교과서 PDF의 2단원으로 노트 만들어줘.
```

원문이 여러 개라면 사용할 파일을 지정하세요. 서로 다른 교과서 전체를 임의로 합치지 않고, 선택한 자료와 범위로 노트를 만듭니다.

### 여러 출판사 교재로 보완하기

사용하는 교과서를 기준으로 지정하면 다른 출판사의 교재와 비교해 기준 교과서에 없는 개념·설명·사례를 보완할 수 있습니다.

1. 기준 교과서와 비교할 교재를 작업 폴더에 넣거나 채팅에 첨부합니다. 두 방법을 함께 사용해도 됩니다.
2. **내가 사용하는 기준 교과서**를 출판사·교과서명 또는 파일명으로 지정합니다.
3. 만들 단원이나 페이지 범위를 정하고, 다른 교재로 보완해 달라고 요청합니다.

```text
내가 사용하는 교과서는 A출판사 통합사회2야.
2단원을 중심으로 B·C출판사 교재에서 빠진 내용을 보완해서 노트 만들어줘.
```

기준 교재의 단원 순서와 번호를 유지하고, 같은 주제·성취기준에 연결되는 내용만 통합합니다. 다른 출판사의 단원 번호가 달라도 내용과 성취기준을 대조해 연결합니다. 기준 교과서가 불분명하면 노트를 만들기 전에 확인합니다.

보완 항목에는 **보완 표시와 출처**를 남깁니다. 출처는 확인 가능한 교재명·출판사·페이지로 적고, 페이지를 알 수 없는 캡처는 파일명이나 이미지 순서로 구분합니다. 보완 내용과 출처는 학생용·교사용 모두에 반영하며, 학생용에는 핵심 개념 빈칸을 넣습니다.

중복 설명이나 범위 밖 심화 내용은 제외합니다. 일부 페이지만 제공하면 **제공된 범위에서 확인되지 않은 내용**을 비교하며, 교과서 전체에 없다고 단정하지 않습니다. 교재 간 설명이 충돌하면 확인되지 않은 내용을 사실로 합치지 않습니다. 자세한 기준은 [여러 출판사 보완 지침](references/multi-publisher-notes.md)에 있습니다.

예를 들어 작업 폴더 이름이 `노트 만들기`라면 결과는 다음 위치에 저장합니다.

```text
노트 만들기/
├── 교과서.pdf
└── 생성된 노트/
    ├── 요약노트(학생용).pdf
    └── 요약노트(교사용).pdf
```

| 파일 | 내용과 기본 형식 |
|---|---|
| 요약노트(학생용).pdf | 핵심 개념을 짧은 빈칸으로 만든 복습용 노트. iPad용 줄노트 형식 |
| 요약노트(교사용).pdf | 빈칸의 답이 모두 보이는 완성본. 수업 화면에 표시하기 좋은 16:9 두 패널 형식 |

두 버전은 하나의 완성 원고에서 만들므로 본문, 번호, 순서가 같습니다. 교사용 내용이 한 화면에 들어가지 않으면 여러 페이지를 하나의 PDF에 담습니다. 기존 결과가 있으면 두 파일에 같은 버전 번호를 붙여 보존합니다.

기본 전달물은 PDF 두 개입니다. PNG나 작업용 Markdown, 다른 파일명·저장 위치가 필요하면 요청에 함께 적어 주세요.

## 노트를 만드는 기준

- 교과서의 실제 대단원·소단원·주제 체계와 의미 있는 상하위 관계를 유지합니다.
- 개념, 분류, 비교 기준, 사례, 인과 관계를 간결하게 정리합니다. 보완 모드에서는 다른 입력 교재에서 확인한 내용을 출처와 함께 추가하며, 어떤 입력 자료에도 없는 사실이나 사례를 만들어 넣지 않습니다.
- 과목·영역·성취기준을 확인해 핵심 개념과 비교·설명·탐구·적용 등 학습 요구를 점검합니다. 교육과정 영역 번호를 교과서 단원 번호로 대신하지 않습니다.
- 학생용 빈칸은 이미 원고에 있는 짧은 핵심 용어를 중심으로 선정하고, 답을 추론할 문맥은 남깁니다.
- 저장한 PDF의 글자, 들여쓰기, 줄바꿈, 페이지 경계, 잘림과 두 버전의 내용 일치를 확인합니다.

이미 정리한 텍스트를 입력하면 원문의 표현과 순서를 보존합니다. 교과서 원문을 입력하는 경우와 처리 방식이 다릅니다. 자세한 작업 규칙은 [SKILL.md](SKILL.md)에 있습니다.

## 렌더러를 직접 실행하기

Python 3.10 이상과 Pillow가 필요합니다. 글꼴은 저장소에 포함되어 있습니다.

`make_note.py`는 **준비된 UTF-8 텍스트·Markdown을 PDF로 렌더링**합니다. 교과서 PDF 읽기, 요약 원고 작성, 성취기준 연결은 스킬을 실행하는 에이전트가 담당합니다.

저장소 폴더에서 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt

# 학생용 원고: 빈칸으로 만들 용어를 [[핵심 용어]]로 표시
.venv/bin/python scripts/make_note.py --input /path/to/student-note.md \
  --pdf-only --output-dir '/path/to/노트 만들기/생성된 노트' \
  --name '요약노트(학생용)'

# 교사용 원고: 학생용 원고의 [[ ]] 표시만 제거한 완성본
.venv/bin/python scripts/make_note.py --input /path/to/teacher-note.md \
  --slide --pdf-only --title '요약노트(교사용)' \
  --output-dir '/path/to/노트 만들기/생성된 노트' \
  --name '요약노트(교사용)'
```

Windows에서는 `py -3 -m venv .venv`로 환경을 만들고 `.venv\Scripts\python.exe`를 사용합니다. 다른 줄노트·모눈·무지 형식이나 추가 옵션은 `python3 scripts/make_note.py --help`로 확인할 수 있습니다.

성취기준 조회는 별도 패키지 없이 실행할 수 있습니다.

```bash
python3 scripts/query_curriculum.py --level 중학교 --subject 국어 --code 9국01-01
python3 scripts/query_curriculum.py --subject 통합사회2 --area '사회정의와 불평등'
```

PDF는 이미지 기반이므로 Goodnotes에 불러와 사용할 수 있지만, 편집 가능한 텍스트나 네이티브 펜 획으로 생성되지는 않습니다.
