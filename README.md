# 굿노트 요약노트 만들기

교과서 원문을 바탕으로 **학생용·교사용 요약노트 PDF**를 만드는 Agent Skills 형식의 스킬입니다. **Codex, Claude Code, Google Antigravity**에서 같은 스킬 지침·스크립트·교육과정 자료를 사용할 수 있습니다. 자료의 단원·소단원 체계를 유지하고, 2022 개정 교육과정 성취기준을 참고해 핵심 개념과 학습 관계를 정리합니다. 여러 출판사 교재를 제공하면 **내가 사용하는 교과서를 중심으로 부족한 내용을 보완**할 수 있습니다.

## 이렇게 사용하세요

**처음이라면 아래의 ‘처음 설치하는 분’을 먼저 읽으세요.** 스킬은 AI 도구가 읽고 따르는 작업 설명서와 보조 프로그램 묶음입니다. GitHub 페이지에서 직접 PDF를 만드는 서비스는 아니며, 설치한 도구의 채팅창에서 제작을 요청합니다.

1. 사용하는 도구에서 스킬을 설치한 뒤 노트를 만들 작업 폴더를 엽니다. 폴더 이름은 자유롭게 정할 수 있습니다.
2. 교과서 PDF나 캡처 자료를 폴더에 넣거나 채팅에 첨부합니다.
3. **“노트 만들어줘”**라고 요청합니다. 필요한 경우 과목, 단원, 페이지 범위를 함께 적습니다.

```text
이 교과서 PDF의 2단원으로 노트 만들어줘.
```

원문이 여러 개라면 사용할 파일을 지정하세요. 서로 다른 교과서 전체를 임의로 합치지 않고, 선택한 자료와 범위로 노트를 만듭니다.

### 여러 출판사 교재로 보완하기

사용하는 교과서를 기준으로 지정하면 다른 출판사의 교재와 비교해 기준 교과서에 없는 개념·설명·사례를 보완할 수 있습니다.

1. 기준 교과서와 비교할 교재를 작업 폴더에 넣거나 채팅에 첨부합니다. 두 방법을 함께 사용해도 됩니다.
2. **내가 사용하는 기준 교과서**를 출판사·교과서명 또는 파일명으로 지정합니다.
3. 만들 단원이나 페이지 범위를 정하고, 다른 교재로 보완해 달라고 요청합니다.

```text
내가 사용하는 교과서는 A출판사 통합사회2야.
2단원을 중심으로 B·C출판사 교재에서 빠진 내용을 보완해서 노트 만들어줘.
```

기준 교재의 단원 순서와 번호를 유지하고, 같은 주제·성취기준에 연결되는 내용만 통합합니다. 다른 출판사의 단원 번호가 달라도 내용과 성취기준을 대조해 연결합니다. 기준 교과서가 불분명하면 노트를 만들기 전에 확인합니다.

보완 항목에는 **보완 표시와 출처**를 남깁니다. 출처는 확인 가능한 교재명·출판사·페이지로 적고, 페이지를 알 수 없는 캡처는 파일명이나 이미지 순서로 구분합니다. 보완 내용과 출처는 학생용·교사용 모두에 반영하며, 학생용에는 핵심 개념 빈칸을 넣습니다.

중복 설명이나 범위 밖 심화 내용은 제외합니다. 일부 페이지만 제공하면 **제공된 범위에서 확인되지 않은 내용**을 비교하며, 교과서 전체에 없다고 단정하지 않습니다. 교재 간 설명이 충돌하면 확인되지 않은 내용을 사실로 합치지 않습니다. 자세한 기준은 [여러 출판사 보완 지침](references/multi-publisher-notes.md)에 있습니다.

예를 들어 작업 폴더 이름이 `노트 만들기`라면 결과는 다음 위치에 저장합니다.

```text
노트 만들기/
├── 교과서.pdf
└── 생성된 노트/
    ├── 요약노트(학생용).pdf
    └── 요약노트(교사용).pdf
```

| 파일 | 내용과 기본 형식 |
|---|---|
| 요약노트(학생용).pdf | 핵심 개념을 짧은 빈칸으로 만든 복습용 노트. iPad용 줄노트 형식 |
| 요약노트(교사용).pdf | 빈칸의 답이 모두 보이는 완성본. 수업 화면에 표시하기 좋은 16:9 두 패널 형식 |

두 버전은 하나의 완성 원고에서 만들므로 본문, 번호, 순서가 같습니다. 교사용 내용이 한 화면에 들어가지 않으면 여러 페이지를 하나의 PDF에 담습니다. 기존 결과가 있으면 두 파일에 같은 버전 번호를 붙여 보존합니다.

기본 전달물은 PDF 두 개입니다. PNG나 작업용 Markdown, 다른 파일명·저장 위치가 필요하면 요청에 함께 적어 주세요.

## 노트를 만드는 기준

- 교과서의 실제 대단원·소단원·주제 체계와 의미 있는 상하위 관계를 유지합니다.
- 개념, 분류, 비교 기준, 사례, 인과 관계를 간결하게 정리합니다. 보완 모드에서는 다른 입력 교재에서 확인한 내용을 출처와 함께 추가하며, 어떤 입력 자료에도 없는 사실이나 사례를 만들어 넣지 않습니다.
- 과목·영역·성취기준을 확인해 핵심 개념과 비교·설명·탐구·적용 등 학습 요구를 점검합니다. 교육과정 영역 번호를 교과서 단원 번호로 대신하지 않습니다.
- 학생용 빈칸은 이미 원고에 있는 짧은 핵심 용어를 중심으로 선정하고, 답을 추론할 문맥은 남깁니다.
- 저장한 PDF의 글자, 들여쓰기, 줄바꿈, 페이지 경계, 잘림과 두 버전의 내용 일치를 확인합니다.

이미 정리한 텍스트를 입력하면 원문의 표현과 순서를 보존합니다. 교과서 원문을 입력하는 경우와 처리 방식이 다릅니다. 자세한 작업 규칙은 [SKILL.md](SKILL.md)에 있습니다.

## Codex·Claude Code·Antigravity에 설치하기

### 처음 설치하는 분

Codex(코덱스), Claude Code(클로드 코드·클코), Google Antigravity(안티그래비티·앤티) 중 **이미 사용하는 도구 하나만 선택**하면 됩니다. 세 도구를 모두 설치할 필요는 없습니다. 해당 도구의 설치와 로그인은 먼저 완료하세요. 일반 ChatGPT·Claude 웹 채팅창에 저장소 주소만 붙이는 것과는 다릅니다.

| 준비할 것 | 설명 |
|---|---|
| AI 도구 | 로컬 파일을 읽고 명령을 실행할 수 있는 Codex, Claude Code 또는 Antigravity |
| 작업 폴더 | 예: 문서 폴더 안에 `노트 만들기`. 원문과 결과를 모으는 장소 |
| 원문 | 교과서 PDF 또는 글자가 읽히는 캡처. 처음에는 한 단원이나 몇 페이지로 시작 |
| 실행 환경 | Git, Python 3.10 이상, Pillow. 설치 여부를 모르면 아래 준비 요청을 사용 |

명령어 사용이 낯설면 **설치한 AI 도구의 채팅창**에 다음 내용을 붙여 넣으세요. 이 요청은 설치를 돕기 위한 것으로, 스킬이 이미 설치되어 있어야 하는 명령은 아닙니다.

```text
나는 처음 사용하는 사람이야. 이 저장소의 요약노트 스킬을 설치하고 싶어.
https://github.com/xodn0109-glitch/goodnotes-handwriting-note

현재 사용하는 도구에 맞는 스킬 경로를 확인하고 저장소 전체를 설치해줘.
기존 설치가 있으면 중복 설치하지 말고 알려줘.
Git과 Python 3.10 이상이 있는지 확인하고,
이 스킬 전용 가상환경에 requirements.txt의 패키지도 설치해줘.
내가 직접 해야 하는 설치나 로그인이 있으면 한 단계씩 안내해줘.
설치 후 SKILL.md, 렌더러, 글꼴, 교육과정 자료를 읽을 수 있는지 확인해줘.
```

도구가 직접 설치할 수 없는 프로그램은 안내에 따라 설치한 뒤 다시 요청하세요. Git·Python 공식 설치 안내는 [Git](https://git-scm.com/downloads)과 [Python](https://www.python.org/downloads/)에서 확인할 수 있습니다.

직접 설치하려면 아래에서 사용하는 도구의 명령만 실행합니다. **`bash` 코드 블록은 터미널에**, **`text` 코드 블록은 AI 채팅창에** 붙여 넣습니다. macOS에서는 터미널, Windows에서는 PowerShell을 사용할 수 있습니다. 아래 설치 명령은 macOS·Linux 기준이며, Windows 사용자는 위 설치 도움 요청을 쓰거나 실제 사용자 폴더 경로에 맞춰 실행하세요. `~`는 사용자 홈 폴더, `.agents`·`.claude`는 숨김 설정 폴더를 뜻합니다.

세 도구 모두 `SKILL.md`와 보조 파일을 읽는 스킬 형식을 지원합니다. **저장소 전체를 설치**해야 렌더러, 글꼴, 교육과정 자료를 함께 사용할 수 있습니다. Python 3.10 이상과 Pillow가 필요하며, 자료를 읽고 로컬 명령을 실행할 수 있는 환경에서 사용하세요. 파일 첨부 기능은 도구에 따라 다르므로 첨부가 어려우면 작업 폴더에 원문을 넣고 파일명을 지정합니다.

Claude Code와 Antigravity는 공식 문서의 스킬 형식과 현재 저장소 구성을 대조해 호환성을 확인했습니다. 두 도구에서 실제 노트 PDF 생성까지 실행 검증한 상태는 아니며, 사용하는 모델과 자료 읽기 도구에 따라 요약 원고가 달라질 수 있습니다.

### Codex

개인 스킬 폴더에 저장소를 내려받는 예시입니다. 이미 같은 이름의 스킬을 설치했다면 중복 설치하지 않고 기존 설치 위치를 사용하세요.

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/xodn0109-glitch/goodnotes-handwriting-note.git \
  ~/.agents/skills/goodnotes-handwriting-note
```

스킬이 인식된 환경에서는 노트 제작을 요청하거나, 지원되는 스킬 선택 기능으로 `goodnotes-handwriting-note`를 지정할 수 있습니다. Codex CLI·IDE에서는 다음처럼 명시할 수 있습니다.

```text
$goodnotes-handwriting-note 이 PDF의 2단원으로 노트 만들어줘.
```

스킬 검색 위치와 호출 방식은 [공식 OpenAI 스킬 안내](https://learn.chatgpt.com/docs/build-skills)를 참고하세요.

### Claude Code

개인 스킬 폴더에 설치하면 여러 프로젝트에서 사용할 수 있습니다.

```bash
mkdir -p ~/.claude/skills
git clone https://github.com/xodn0109-glitch/goodnotes-handwriting-note.git \
  ~/.claude/skills/goodnotes-handwriting-note
```

```text
/goodnotes-handwriting-note 이 PDF의 2단원으로 노트 만들어줘.
```

프로젝트에서만 사용하려면 `<작업 폴더>/.claude/skills/goodnotes-handwriting-note`에 설치합니다. 자세한 내용은 [Claude Code 공식 스킬 안내](https://code.claude.com/docs/en/skills)를 참고하세요.

### Google Antigravity

작업 폴더에서 다음 명령으로 프로젝트용 스킬을 설치합니다.

```bash
mkdir -p .agents/skills
git clone https://github.com/xodn0109-glitch/goodnotes-handwriting-note.git \
  .agents/skills/goodnotes-handwriting-note
```

설치한 작업 폴더를 열고 스킬 이름을 지정해 요청합니다.

```text
goodnotes-handwriting-note 스킬로 A출판사 교과서를 기준 삼아
B·C출판사 교재에서 빠진 내용을 보완해서 노트 만들어줘.
```

Antigravity 2.0에서는 `/goodnotes-handwriting-note`로 직접 호출할 수도 있습니다. 전역 설치 경로는 제품에 따라 다르므로 [Google Antigravity 공식 스킬 안내](https://www.antigravity.google/docs/skills?tab=ide)를 확인하세요.

### 첫 노트 만들기

1. 컴퓨터에 `노트 만들기` 폴더를 만들고, 사용할 PDF를 `교과서.pdf`라는 이름으로 넣습니다. 다른 이름을 써도 되지만 요청에 실제 파일명을 적으세요.
2. 사용하는 도구에서 그 폴더를 작업 대상으로 엽니다. 폴더를 여는 방법이 익숙하지 않으면 채팅에 실제 전체 경로를 적고 작업 폴더로 사용해 달라고 요청합니다. Antigravity 프로젝트용으로 설치했다면 스킬을 설치한 작업 폴더를 사용하세요.
3. 채팅창에 다음 요청을 붙여 넣습니다. ‘2단원’은 원하는 단원이나 페이지 범위로 바꾸세요.

```text
goodnotes-handwriting-note 스킬을 사용해줘.
현재 작업 폴더의 교과서.pdf에서 2단원으로 요약노트를 만들어줘.
2022 개정 교육과정 성취기준과 교과서의 단원 체계를 참고하고,
생성된 노트 폴더에 학생용과 교사용 PDF를 각각 저장해줘.
```

4. 도구가 파일 읽기나 프로그램 실행 권한을 요청하면 대상 파일과 명령을 확인하고 허용합니다. 원문을 읽고 두 PDF를 생성할 때까지 기다립니다.
5. 작업 폴더의 `생성된 노트`를 열어 PDF 두 개를 확인합니다. 학생용의 빈칸과 교사용의 답, 글자 잘림, 단원 순서와 출처를 살펴보세요. 학생용 PDF는 Goodnotes에서 가져와 필기하고, 교사용 PDF는 수업 화면에 띄울 수 있습니다.

수정도 같은 채팅에서 요청하면 됩니다.

```text
학생용 빈칸을 핵심 개념 위주로 줄여줘.
두 버전의 본문과 순서는 일치시키고 기존 PDF는 보존해줘.
```

### 막혔을 때

| 상황 | 해결 방법 |
|---|---|
| 스킬을 찾지 못함 | 설치 경로 안에 `goodnotes-handwriting-note/SKILL.md`가 있는지 확인하고 새 채팅이나 도구 재시작 후 다시 요청합니다. 도구에 설치 경로를 알려 주고 확인을 요청해도 됩니다. |
| PDF를 찾지 못함 | 실제 파일명과 작업 폴더 전체 경로를 알려 줍니다. 첨부 기능이 없는 도구에서는 로컬 폴더에 넣습니다. |
| `python` 또는 `PIL` 오류 | 위 설치 도움 요청으로 Python과 스킬 전용 가상환경의 패키지를 점검합니다. Pillow의 Python 모듈 이름은 `PIL`입니다. |
| 저장소 폴더가 이미 있다는 오류 | 같은 위치에 다시 `git clone`하지 말고 기존 스킬의 설치 상태를 확인해 달라고 요청합니다. |
| 원문 글자를 읽지 못함 | 선명한 캡처나 텍스트가 들어 있는 PDF를 제공합니다. 처음에는 읽기 쉬운 몇 페이지로 시도합니다. |
| 파일이 어디에 저장됐는지 모름 | ‘생성한 학생용·교사용 PDF의 전체 경로를 알려줘’라고 요청합니다. |

업데이트하려면 도구에 ‘이 스킬의 로컬 수정 여부를 먼저 확인하고, 수정이 없으면 GitHub의 최신 버전으로 업데이트해줘’라고 요청하세요. 아래 렌더러 직접 실행 안내는 명령어로 PDF를 만들고 싶은 사용자를 위한 추가 설명이며, 일반적인 노트 요청에는 직접 실행할 필요가 없습니다.

## 렌더러를 직접 실행하기

Python 3.10 이상과 Pillow가 필요합니다. 글꼴은 저장소에 포함되어 있습니다.

`make_note.py`는 **준비된 UTF-8 텍스트·Markdown을 PDF로 렌더링**합니다. 교과서 PDF 읽기, 요약 원고 작성, 성취기준 연결은 스킬을 실행하는 에이전트가 담당합니다.

저장소 폴더에서 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt

# 학생용 원고: 빈칸으로 만들 용어를 [[핵심 용어]]로 표시
.venv/bin/python scripts/make_note.py --input /path/to/student-note.md \
  --pdf-only --output-dir '/path/to/노트 만들기/생성된 노트' \
  --name '요약노트(학생용)'

# 교사용 원고: 학생용 원고의 [[ ]] 표시만 제거한 완성본
.venv/bin/python scripts/make_note.py --input /path/to/teacher-note.md \
  --slide --pdf-only --title '요약노트(교사용)' \
  --output-dir '/path/to/노트 만들기/생성된 노트' \
  --name '요약노트(교사용)'
```

Windows에서는 `py -3 -m venv .venv`로 환경을 만들고 `.venv\Scripts\python.exe`를 사용합니다. 다른 줄노트·모눈·무지 형식이나 추가 옵션은 `python3 scripts/make_note.py --help`로 확인할 수 있습니다.

성취기준 조회는 별도 패키지 없이 실행할 수 있습니다.

```bash
python3 scripts/query_curriculum.py --level 중학교 --subject 국어 --code 9국01-01
python3 scripts/query_curriculum.py --subject 통합사회2 --area '사회정의와 불평등'
```

PDF는 이미지 기반이므로 Goodnotes에 불러와 사용할 수 있지만, 편집 가능한 텍스트나 네이티브 펜 획으로 생성되지는 않습니다.
