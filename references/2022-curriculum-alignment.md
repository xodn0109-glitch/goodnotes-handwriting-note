# 2022 개정 교육과정과 필기노트 연결

## 범위와 출처

사용자가 지정한 로컬 `2022개정 교육과정` 자료 중 중학교·고등학교 자료를 스킬 내부에 사본으로 포함했다. [목차](curriculum-2022/INDEX.md)와 [출처 기록](curriculum-2022/manifest.json)에 범위·개수·해시를 기록했다. 검색 대상은 중학교 714개, 고등학교 2,173개, 총 2,887개 성취기준이다. 고등학교는 로컬 코퍼스의 교과 전체, 중학교는 기본 교과와 한문·환경·생활외국어 8개 언어·보건·진로와 직업을 포함한다. 특수교육·직업계 전문 교과 등 로컬에 없는 범위까지 포함한 국가 전체 성취기준 목록으로 표현하지 않는다.

초등학교 성취기준 73개는 검색 인덱스에서 제외했다. 원문 보존을 위해 사회·도덕 원문 파일 안에 함께 있는 초등학교 본문은 그대로 두었으나 노트 연결 대상으로 사용하지 않는다. 총론과 창의적 체험활동은 필요한 경우 맥락을 확인하는 자료이며 코드형 성취기준이 없다.

원문은 로컬 분할본의 사본이다. 최신 고시를 온라인으로 자동 동기화하는 자료가 아니다. 스냅샷 이후 사용자가 제공한 새 교육과정 자료나 개정본이 있으면 그 자료를 우선하고 버전 차이를 명시한다. 사용자의 원래 교육과정 폴더는 수정하지 않는다.

## 필요한 기준만 조회

스킬 폴더를 기준으로 실행한다. 다른 작업 폴더에서는 스크립트의 절대 경로를 쓴다. 표준 라이브러리만 필요하다.

```bash
python3 scripts/query_curriculum.py --subject 통합사회2 --area '사회정의와 불평등'
python3 scripts/query_curriculum.py --level 중학교 --subject 사회 --text 기후
python3 scripts/query_curriculum.py --subject 공통수학1 --code 10공수1-01-01
python3 scripts/query_curriculum.py --file 07_체육과 --code 12스문01-01 --format json
```

필터는 함께 적용할 수 있다. `--code`는 정확 일치, `--subject`, `--area`, `--file`, `--text`는 부분 일치다. 기본 최대 50개이며, 결과가 잘리면 필터를 좁히거나 `--limit`을 늘린다. 일치 없음은 종료 코드 1, 조회 실패는 오류이며 실제 기준이 없는 것과 구분한다.

같은 코드가 다른 교과에 존재한다. 예를 들어 `[12스문01-01]`은 스포츠 문화와 스페인어권 문화에 모두 있다. 반드시 `(file, code)`와 과목으로 식별하고 학교급도 확인한다. 코드만으로 조회해 여러 결과가 나오면 하나를 임의로 선택하지 않는다.

출력의 `physical_line`과 `source`는 원문 사본의 실제 행 번호다. `line`은 H1 기준 상대 행이므로 인용 위치로 혼용하지 않는다. 필요한 해설·적용 시 고려 사항은 해당 원문 파일의 반환 행 주변에서 확인한다. 성취기준 문장과 해설, 교과서 사례, 작성자의 해석을 구분한다. 영역 이름이 없는 인덱스 항목은 원문 주변 제목을 확인하고 영역 이름을 지어내지 않는다.

## 노트와 빈칸에 반영

1. 제공된 교과서 표제·과목·학년·단원 또는 사용자 설명으로 교육과정과 과목을 확인한다. 내용만으로 여러 과목이 가능하면 후보로만 취급하고 일반 개념 빈칸을 사용한다. 명확한 자료는 추가 질문 없이 진행한다.
2. 해당 단원의 성취기준을 조회하고 원문 문장 및 필요한 해설을 확인한다. 직접 연결되는 기준을 우선하고 보조 기준은 실제로 자료가 다루는 경우만 연결한다. 다른 단원의 기준까지 빈칸을 채우기 위해 끌어오지 않는다.
3. 교과서 재구성에서는 성취기준의 개념과 학습 동사를 함께 살핀다. 비교는 비교 기준과 차이를, 설명은 관계와 근거를, 탐구·분석은 자료와 인과 관계를, 적용·제안은 판단 기준과 실천 내용을 드러낸다. 제공된 자료에 없는 내용·사례·활동은 추가하지 않는다. 표현·실기·태도 영역은 필기노트가 지원하는 범위를 구분하고 빈칸 정답만으로 달성 여부를 판단하지 않는다.
4. 완성본에 이미 있는 짧은 핵심 용어를 우선 빈칸으로 선정한다. 기준을 이해하는 데 필요한 비교 축·맥락·연결어·문장 구조는 남긴다. 성취기준에 나온 단어라도 원고에 없으면 새로 삽입하지 않는다. 기존 스킬의 빈칸 밀도와 수업용·복습용 일치 규칙을 유지한다.
5. 작업용 초안 또는 별도 매핑 기록에는 학교급, 과목, 영역, 코드, 원문 위치와 선택 이유를 남긴다. 사용자가 요구하지 않은 성취기준 목록을 노트 본문에 길게 추가하지 않는다. 공식 문장과 노트의 요약·추론을 구별한다.

## 원문 품질과 검증

원문 분할본에는 변환 결함이 남아 있다. 확인된 문제는 조회 결과의 `source_issues`로 표시한다. 깨진 글자나 누락된 수학 기호를 추측해서 보충하지 않는다. 해당 부분이 노트 제작에 필수이면 사용자가 제공한 원본이나 확인 가능한 공식 원문으로 대조하고, 확인 전에는 연결을 미확정으로 둔다. `source_issues`가 비어 있어도 원본 변환이 완전하다는 보장은 없다. 특히 수학 수식·표·도형은 제공된 교과서 또는 원본과 대조한다.

성취기준을 연결한 뒤에는 원고의 사실·개념·관계 보존과 두 버전의 일치를 확인한다. PDF·PNG 렌더 검증은 기존 스킬 지침을 따른다. 교육과정 조회만으로 필기노트의 시각 검증을 대체하지 않는다.
