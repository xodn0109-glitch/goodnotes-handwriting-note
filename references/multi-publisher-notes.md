# 여러 출판사 교재로 기준 교과서 보완하기

사용자가 여러 교재를 제공하고 사용하는 교과서 중심의 보완을 요청할 때 적용한다. 입력 방식은 작업 폴더의 원문, 채팅 첨부, 두 방식의 조합을 모두 허용한다.

## 기준 교재 확인

- 사용자가 지정한 교과서를 기준 교재로 삼는다. 앞선 대화에서 지정한 교과서도 유효하다. 파일명·표지·판권에서 과목, 출판사, 교육과정 및 판본을 확인하고 확인되지 않은 항목은 미상으로 둔다.
- 기준 교재가 명확하지 않으면 후보를 확인한 뒤 사용하는 교과서를 한 번 묻는다. 파일 순서나 업로드 순서만으로 기준 교재를 정하지 않는다. 답변 전에는 자료 목록 확인 등 독립적인 작업만 진행한다.
- 사용자가 비교 대상으로 제공한 다른 교재를 보완 자료로 사용한다. 관련 없는 파일이나 생성된 노트는 비교 대상에 넣지 않는다.

## 내용 비교와 선정

1. 기준 교재의 요청 범위를 읽어 단원·소단원·주제·주요 개념·비교 축·사례를 정리한다. 이 구조가 최종 노트의 골격이다.
2. 보완 교재의 같은 과목·학습 범위를 찾는다. 출판사마다 단원 순서와 번호가 다르므로 주제와 성취기준을 통해 대응시키고 단원 번호만으로 맞추지 않는다. 다른 교육과정·학교급의 내용을 같은 범위로 간주하지 않는다.
3. 내용이 겹치는 부분, 설명이 더 구체적인 부분, 기준 교재에서 확인되지 않는 부분, 서로 충돌하는 부분을 구분한다. 표현만 다른 중복 설명이나 사례를 모두 추가하지 않는다.
4. 요청 단원과 해당 성취기준의 학습 요구에 직접 연결되는 누락 개념, 부족한 정의·비교 기준·인과 설명, 이해에 도움이 되는 사례를 우선 보완한다. 보완 교재에 있다는 이유만으로 범위 밖 심화 내용이나 다른 단원을 끌어오지 않는다.
5. 보완 내용은 해당 기준 교재 항목 아래에 짧게 통합한다. 다른 교재의 소단원 번호를 최종 노트의 번호로 가져오거나 기준 교재의 순서를 바꾸지 않는다. 기준 교재에 없던 내용이 어떤 주제에 연결되는지 분명히 한다.

제공된 자료가 일부 페이지만 담고 있으면 ‘교과서 전체에 없는 내용’이라고 단정하지 않고 ‘제공된 기준 교재 범위에서 확인되지 않음’으로 기록한다. 해당 범위가 불완전해 비교에 필수적인 내용이 빠졌다면 그 한계를 밝힌다.

교재마다 정의·수치·분류·설명이 충돌하면 임의로 섞거나 기준 교재를 이유 없이 바꾸지 않는다. 양쪽 출처와 차이를 확인하고, 필요하면 해당 성취기준 원문 또는 확인 가능한 원자료로 대조한다. 해결되지 않은 충돌은 노트에 확정 내용으로 넣지 않고 사용자에게 알린다. 사실 오류가 확인된 내용을 기준 교재에 있다는 이유로 유지하지 않는다.

## 출처와 두 버전

- 보완 항목에는 짧은 `보완` 표시를 붙이고, 해당 주제 끝에 출판사·교재명·확인한 쪽수를 간결하게 적는다. 인쇄 쪽수와 PDF 페이지 번호를 구분하고, 쪽수·출판사를 알 수 없는 캡처는 입력 파일명과 이미지 순서로 식별한다. 출처를 추측하지 않는다.
- 상세 작업 기록에는 기준 교재 위치, 보완 교재 위치, 대응 성취기준, 추가 이유, 원문에서 확인한 내용을 남긴다. 기록은 생성된 노트 폴더 밖의 작업 공간에 두고 기본 전달물은 PDF 두 개로 유지한다.
- 출처와 보완 표시를 포함한 하나의 완성 원고에서 학생용·교사용을 만든다. 두 버전의 번호·내용·순서·출처는 동일하며 학생용의 핵심 용어에만 빈칸 표시를 적용한다. 교사용에만 보완 개념을 추가하지 않는다.
- 보완 내용의 출처가 실제 입력 자료에 있고, 기준 교재의 중요한 내용이 빠지지 않았으며, 불필요한 중복과 범위 밖 내용이 없는지 대조한다. 이후 기존 PDF 렌더·육안 검증 절차를 따른다.
